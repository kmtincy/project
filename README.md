# Banking and Transaction Management Sysetm
[watch the project demo](https://drive.google.com/file/d/1Dm9KauEp4MUi3RmRjHMu0uCluHxwsh6f/view?usp=sharing)

A console-based Banking & Transaction Management System developed in Python to manage customers, bank accounts, deposits, withdrawals, balances, and transaction history.

## Features

- Customer Management
- Account Management
- Create and view customers
- Create and manage bank accounts
- Deposit money
- Withdraw money
- Check account balance
- View transaction history
- Account validation
- Transaction recording

## Technologies Used

- Python
- Object-Oriented Programming
- Regular Expressions
